Mail DNS Check Automation

Run the same MX, SPF, DKIM and DMARC checks from scripts, scheduled tasks and CI. Each run writes an HTML report with the results embedded as JSON, so a job can read them and act on failures.

DKIM selectors

DNS can't list a domain's DKIM selectors, so every check looks for keys at a fixed list of common selectors, plus any you add. The full list with who uses each one is under Selector list on the main page.

Find your selector

  • Open a message sent from the domain and view its headers. The DKIM-Signature header has an s= tag, for example s=mycorp2024. That value is the selector.
  • Microsoft 365 always uses selector1 and selector2. These are already checked.
  • Google Workspace shows the selector under Admin console → Apps → Google Workspace → Gmail → Authenticate email. The default is google.
  • Sending services (SendGrid, Mailchimp, HubSpot and others) show their selectors on the DNS records page for your domain.

Add selectors

WhereHowExample
Web pageExtra DKIM selectors field, or s= in the link?d=contoso.com&s=mycorp2024,s2025
Python--selector (-s), space or comma separated--selector mycorp2024 s2025
PowerShell-Selector, comma separated-Selector mycorp2024,s2025

Keep selectors in a file

For scheduled runs, keep your selectors in a text file next to domains.txt, one per line, and pass them in. Lines starting with # are skipped. The file needs at least one selector, or Python stops with a usage error.

Bash
python3 python/check_mail_dns.py --domains domains.txt \
  --selector $(grep -v '^#' selectors.txt) \
  --output reports/mail-dns.html
PowerShell
$selectors = Get-Content .\selectors.txt | Where-Object { $_ -and $_ -notmatch '^#' }
.\powershell\Check-MailDns.ps1 -Domains .\domains.txt -Selector $selectors -Output .\reports\mail-dns.html

Web links

The web page runs a check as soon as it opens with domains in the link. Use this in ticket templates, runbooks or monitoring dashboards.

ParameterMeaning
d (or domains)Domains to check, comma separated.
sExtra DKIM selectors, comma separated.
URL
https://groenkaal.github.io/mail-dns-check/?d=contoso.com,fabrikam.com&s=mycorp2024

The page runs in the viewer's browser, so it can't be called as an API. For unattended runs, use one of the scripts below.

Python

Needs Python 3.9 or later and dnspython. Pass --output in automations; without it the script stops and asks where to save the report.

Bash
git clone https://github.com/Groenkaal/mail-dns-check.git
cd mail-dns-check
pip install -r python/requirements.txt
python3 python/check_mail_dns.py --domains domains.txt --output reports/mail-dns.html
OptionMeaning
-d, --domains FILEDomain list. Default: domains.txt in the repo root.
-D, --domain A BDomains on the command line instead of a file.
-s, --selector A BExtra DKIM selectors.
-o, --output FILEReport path. Folders are created if needed.
-n, --nameserver IPDNS server to use instead of the system resolver. Turns off the public-resolver retry for empty TXT answers.

The script exits with code 0 whenever it writes the report, whatever the results. To fail a job on bad results, read the report as shown in Reading results.

PowerShell

Works in Windows PowerShell 5.1 and PowerShell 7. Pass -Output in automations so it doesn't stop to ask for a path.

PowerShell
.\powershell\Check-MailDns.ps1 -Domains .\domains.txt -Selector mycorp2024 -Output C:\Reports\mail-dns.html

Run from GitHub without cloning

Scheduled runs

Windows Task Scheduler

Weekly run every Monday at 07:00, writing a dated report. Run this once in an elevated PowerShell window.

PowerShell
$script = 'C:\Tools\mail-dns-check\powershell\Check-MailDns.ps1'
$taskArgs = "-NoProfile -ExecutionPolicy Bypass -Command `"& '$script' -Domains 'C:\Tools\mail-dns-check\domains.txt' -Output ('C:\Reports\mail-dns-' + (Get-Date -Format yyyy-MM-dd) + '.html')`""
$action  = New-ScheduledTaskAction -Execute 'powershell.exe' -Argument $taskArgs
$trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Monday -At 7am
Register-ScheduledTask -TaskName 'Mail DNS Check' -Action $action -Trigger $trigger

cron (Linux, macOS)

Same schedule. In crontab, % has to be escaped as \%.

crontab
0 7 * * 1  cd /opt/mail-dns-check && python3 python/check_mail_dns.py --domains domains.txt --output reports/mail-dns-$(date +\%F).html

GitHub Actions

Put this in .github/workflows/mail-dns.yml in a copy of the repo. It runs every Monday and on demand, saves the report as a downloadable artifact, and fails the run when any domain fails.

YAML
name: Mail DNS check

on:
  schedule:
    - cron: "0 6 * * 1"   # Mondays 06:00 UTC
  workflow_dispatch:

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -r python/requirements.txt
      - name: Run checks
        run: python python/check_mail_dns.py --domains domains.txt --selector mycorp2024 --output report/mail-dns-report.html
      - uses: actions/upload-artifact@v4
        with:
          name: mail-dns-report
          path: report/
      - name: Fail on failing domains
        run: python scripts/read_report.py report/mail-dns-report.html

Save the reader from Reading results as scripts/read_report.py for the last step. Leave that step out if you only want the report.

Reading results

Every report embeds its results as JSON in <script id="report-data" type="application/json">. Each domain has an overall status and one entry per check.

FieldContents
domainThe domain checked.
overallpass, warn or fail: the worst of SPF, DKIM and DMARC, or fail when there is no MX.
providerMail provider found from MX, such as Microsoft 365, or null.
tenantfound, plus id and region when the domain has a Microsoft 365 tenant.
checks.mx, .spf, .dkim, .dmarcEach has status (pass, warn, fail, info), summary, records and findings (each with level and text).

Python

Prints one line per domain and exits with code 1 when any domain fails.

Python
import json, re, sys

html = open(sys.argv[1], encoding="utf-8").read()
raw = re.search(r'<script id="report-data" type="application/json">(.*?)</script>', html, re.S).group(1)
report = json.loads(raw)

for d in report["domains"]:
    c = d["checks"]
    print(f'{d["domain"]:<24} {d["overall"]:<5} spf={c["spf"]["status"]} dkim={c["dkim"]["status"]} dmarc={c["dmarc"]["status"]}')

failing = [d["domain"] for d in report["domains"] if d["overall"] == "fail"]
if failing:
    print("Failing:", ", ".join(failing))
    sys.exit(1)

PowerShell

PowerShell
$html = Get-Content .\mail-dns.html -Raw -Encoding UTF8
$json = [regex]::Match($html, '(?s)<script id="report-data" type="application/json">(.*?)</script>').Groups[1].Value
$report = $json | ConvertFrom-Json

$report.domains | Select-Object domain, overall,
    @{ n = 'spf';   e = { $_.checks.spf.status } },
    @{ n = 'dkim';  e = { $_.checks.dkim.status } },
    @{ n = 'dmarc'; e = { $_.checks.dmarc.status } } | Format-Table

if (@($report.domains | Where-Object overall -eq 'fail').Count) { exit 1 }
